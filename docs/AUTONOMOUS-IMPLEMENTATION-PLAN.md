## 9. Verification Strategy

Per task, in strict order: **static check → unit test → integration test → runtime observation → review → fix → regression.**

1. `python -m compileall`, `ruff`, `mypy`
2. `pytest -q`
3. boot `uvicorn`, hit `/api/health`, run the E2E script against it, print real responses
4. `npm run lint`, `npm run typecheck`, `npm run build`
5. Security pass: no secrets in tree, no unvalidated outbound URL, no `dangerouslySetInnerHTML`, ownership on every route
6. UX pass: design tokens only; every screen has loading/empty/error; REAL/MOCKED badges match `MVP-SCOPE.md`

A task is `COMPLETE` only at `IMPLEMENTED + TESTED + VERIFIED + INTEGRATED`. Anything less is `VERIFICATION_PENDING` or `REJECTED`.

## 10. Known Blockers

| Blocker | Class | Handling |
|---|---|---|
| No PostgreSQL | external infra | SQLite fallback preserving the SQLAlchemy model contract; Postgres DDL + RLS shipped and documented as the production path. **Not blocking.** |
| No Redis | external infra | Threaded queue behind the same `JobQueue` interface; RQ worker shipped for production. **Not blocking.** |
| No ffmpeg | external infra | Probe/transcode/render capability-detect; degraded states are surfaced as `FFMPEG_UNAVAILABLE` with a real, honest message. Timeline, EDL, matching and clip logic remain real. **Not blocking the pipeline design; blocks the binary render here.** |
| No Supabase | external infra | Local storage + signed-URL-shaped API so the client contract is unchanged. **Not blocking.** |
| No LLM key | credential | Grok adapter is real code against the OpenAI-compatible xAI endpoint; the `DEV` provider produces deterministic, schema-valid output so every flow runs. All such output is labelled in the UI. **Not blocking.** |

**No blocker prevents completion of the product within the constraints above.** Genuine remaining limitations are recorded in `FINAL-VERIFICATION.md`.
